# PasswordSecurity-Psec-
O PSec se caracteriza como um gerador de senhas seguro, o qual combina diversos conteúdos de senhas, o usuário decide, incluindo letras, números e símbolos do teclado padrão. Tal aplicação permite ao usuário personalizar sua senha, informando como deseja que a mesma se inicie ou deixando com que o algoritmo gere aleatoriamente sua senha.
