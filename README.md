# 🔐 PSec - Gerador de Senhas Seguras

Um aplicativo para criar senhas fortes, personalizáveis e seguras, garantindo melhores práticas de segurança e proteção de dados.
Ideal para usuários finais, desenvolvedores e equipes que desejam gerar senhas complexas rapidamente.

# 🚀 Funcionalidades : 

✔️ Geração de senhas com tamanho personalizado
--> Cabe ao usuário decidir qual o tamanho da sua senha, sendo o mínimo de 10 caracteres e o máximo sendo 20

✔️ Inclusão opcional de:
--> Símbolos especiais
--> Letras 
--> Números

✔️ Perosonalização da senha pelo usuário
--> O usuário pode decidir como sua senha deve iniciar, personalizando-a do seu jeito e deixando o restante para o algoritmo gerar aleatoriamente

✔️ Apresenta a força da senha
--> Caso a combinação seja de apenas um tipo de caractere, a senha é FRACA
Ex.: Selecionar apenas Letras
--> Caso a combinação seja de apenas dois tipos de caracteres, a senha é MÉDIA
Ex.: Selecionar apenas Números e Letras
--> Caso a combinação seja de três tipos de caracteres, a senha é SEGURA
Ex.: Selecionar Números, Letras e Símbolos

✔️ Cópia rápida da senha gerada

✔️ Interface simples e intuitiva

✔️ 100% offline

# 🛠️ Tecnologias Utilizadas :

--> HTML5, CSS3, JavaScript

# ⚙️ Configurações Disponíveis :

--> O usuário pode definir : 
  - Tamanho da senha
  - Incluir letras maiúsculas e minúsculas (A-Z)
  - Incluir números (0-9)
  - Incluir símbolos (!@#$%^&*()-_=+[]{}/?)
  - Copiar senha automaticamente com um clique
